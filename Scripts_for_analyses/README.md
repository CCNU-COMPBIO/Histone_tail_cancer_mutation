# Scripts_for_analyses
You can browse the following folders:
1. [MMGBSA_calculation](./MMGBSA_calculation): scripts for calculating tail-DNA binding free energies using MM/GBSA approach.
2. [MSM_analysis](./MSM_analysis): scripts for Markov State Model construction
3. [VMD_tcl_scripts_for_nucleosome_trajectories_analysis](./VMD_tcl_scripts_for_nucleosome_trajectories_analysis): scripts for analyzing MD trajectories using VMD.
