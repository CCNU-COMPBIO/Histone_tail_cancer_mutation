You can browse the following folders:

Bound_ions_analysis : scripts for calculating bound divalent ions.
Gaping_distance: scripts for calculating gaping distance at different SHLs.
MMPBSA_calculation: scripts for calculating tail-DNA binding free energies using MM/GBSA approach.
Residence_time: scripts for calculating tail residence time on DNA.
VMD_tcl_scripts_for_trajectories_analysis: scripts for analyzing MD trajectories using VMD.
Youngs_modulus: scripts for calculating Young's modulus of nucleosome using MD trajectories.
