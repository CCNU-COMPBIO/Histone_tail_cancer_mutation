1. [force_field](./force_field): Force field and water model parameter files

2. [simulation_parameter](./simulation_parameter): Parameter files for each simulation stage

3. [structure_files](./structure_files): Structure PDB files for all simulated systems

4. [systems_run_production_directly](./systems_run_production_directly): TPR files are provided for each system, so the production run can be executed directly.

5. [topol_itp](./topol_itp): Multiple ITP files automatically generated due to the multi-chain structure of the nucleosome.
