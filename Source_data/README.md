# Source data
You can browse all source data in the following folders:
1. [Distance_calculation](./Distance_calculation): results of histone tail end-to-end distance calculation
2. [MMGBSA_calculation](./MMGBSA_calculation): results of energy calculations using the MM/GBSA approach
3. [RG_calculation](./RG_calculation): results of histone tail radius of gyration calculation
4. [SASA_calculation](./SASA_calculation): results of nucleosome solvent-accessible surface area calculation
5. [Secondary_structure_calculation](./Secondary_structure_calculation): results of secondary structure analysis using the DSSP algorithm
6. [VMD_tcl_scripts_for_nucleosome_trajectories_analysis](./VMD_tcl_scripts_for_nucleosome_trajectories_analysis): results of nucleosome MD trajectory analysis generated by VMD
7. [intra-tail_contact_calculation](./intra-tail_contact_calculation): results of intra-tail inter-atomic contact count calculations
