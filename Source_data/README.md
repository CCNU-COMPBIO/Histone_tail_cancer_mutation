# Source data
You can browse all source data in the following folders:
1. [Distance_calculation](./Distance_calculation): results of histone tail end-to-end distance calculation
2. [MD2NMR_results](./MD2NMR_results): results of NMR spectral parameters，τc
3. [MMGBSA_calculation](./MMGBSA_calculation): results of energy calculations using the MM/GBSA approach
4. [RG_calculation](./RG_calculation): results of histone tail radius of gyration calculation
5. [SASA_calculation](./SASA_calculation): results of nucleosome solvent-accessible surface area calculation
6. [Secondary_structure_calculation](./Secondary_structure_calculation): results of secondary structure analysis using the DSSP algorithm
7. [Tail_DNA_contact](./Tail_DNA_contact): results of Tail_DNA_contact generated by VMD
8. [intra-tail_contact_calculation](./intra-tail_contact_calculation): results of intra-tail inter-atomic contact count calculations
